# Target-Role Competency Matrix

## Target Roles

This handbook is being shaped for Staff, Senior Staff, Principal Engineer, and PMTS individual-contributor roles at high-scale product, cloud, data, and AI-platform companies.

The requirements below are a distilled preparation matrix from the job descriptions reviewed for Atlassian Principal Engineer, Databricks Senior Staff Software Engineer, Salesforce Engineering Lead / PMTS-style roles, and Google Staff Software Engineer in AI and Infrastructure. It is a preparation aid, not a reproduction of any job posting.

## Shared Requirements

| Competency | What strong evidence looks like |
| --- | --- |
| Software-engineering depth | Expert fluency in a primary backend language, excellent code quality, practical data structures and algorithms, and sound object-oriented design |
| Large-scale systems | Designs and operates distributed, available, fault-tolerant systems with meaningful load, data, tenancy, or customer impact |
| Architecture | Defines boundaries, data flows, interfaces, standards, trade-offs, migration plans, and long-term technical direction |
| Delivery ownership | Leads work from ambiguous problem through design, implementation, testing, launch, operations, and measurable improvement |
| Reliability and performance | Uses SLOs, observability, capacity planning, load testing, incident learning, profiling, and failure-mode analysis |
| Data and messaging | Understands relational and non-relational data stores, SQL, caching, queues, event-driven systems, locking, scheduling, and workload distribution |
| Cross-team influence | Aligns teams without direct authority; clarifies priorities, constraints, success metrics, ownership, and timelines |
| Technical leadership | Mentors engineers, raises code-review and documentation standards, leads design reviews, and grows organizational capability |
| Customer and business impact | Connects technical decisions to reliability, security, velocity, cost, adoption, customer experience, or revenue outcomes |
| AI-native engineering | Evaluates AI-assisted output critically; designs secure agent/human workflows; maintains clear system context, constraints, and standards |

## Company Emphasis

| Target | Particular emphasis |
| --- | --- |
| Atlassian Principal Engineer | Complex design-to-launch delivery, reusable engineering standards, broad product impact, meaningful code reviews, mentorship, and customer judgment |
| Databricks Senior Staff | Deep distributed-systems internals, performance profiling/debugging, large-cluster operations, multi-year vision, and data infrastructure at scale |
| Salesforce Engineering Lead / PMTS-style | Multi-tenant SaaS, public cloud, databases and SQL, queues and scheduling, secure AI-agent workflows, and shared system context |

## Evidence Portfolio

Build and be ready to discuss the following:

1. One end-to-end, production-style system in [Solutions](../solutions/README.md).
2. A design document that states requirements, estimates, alternatives, trade-offs, APIs, data model, rollout, and failure modes.
3. Architecture decision records (ADRs) for consequential choices.
4. Load-test results, SLOs, dashboards, alerts, and a capacity or cost model.
5. One incident or failure-mode exercise with a blameless review and corrective actions.
6. A migration or multi-phase roadmap that de-risks a long-term technical vision.
7. Ten leadership stories with measurable outcomes.

## Gap-Assessment Checklist

- [ ] I can solve and clearly explain common DSA patterns.
- [ ] I can design a multi-tenant, distributed service and defend its trade-offs.
- [ ] I can explain consistency, idempotency, retries, queues, locking, scheduling, and backpressure.
- [ ] I can debug a performance or reliability issue using metrics, logs, traces, and profiling.
- [ ] I have led work across more than one team or can show equivalent influence.
- [ ] I can describe a multi-quarter technical vision as incremental, measurable milestones.
- [ ] I have mentored others or improved an engineering practice.
- [ ] I can assess human- or AI-generated code for correctness, security, performance, and maintainability.
