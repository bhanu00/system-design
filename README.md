# Software Engineering Handbook

An evolving, practical handbook for becoming a stronger software engineer: from programming foundations to Staff and Principal-level system design, architecture, and technical leadership.

This repository combines study notes, interview preparation, real-world case studies, and runnable proof-of-concept applications. Read it like a book, or use the index to jump directly to a topic.

## Start Here

1. **[Learning path](LEARNING_PATH.md)** - a guided, role-based sequence.
2. **[Book index](INDEX.md)** - the complete table of contents.
3. **[Foundations](foundations/README.md)** - a good first technical chapter.

## How to Use This Repository

- **Newer engineers:** follow the [learning path](LEARNING_PATH.md) from foundations through DSA and object-oriented design.
- **Senior/Staff candidates:** focus on system design, distributed systems, architecture, reliability, and the interview material.
- **Hands-on learners:** pair a chapter with a related implementation in [solutions/](solutions/README.md) or the GitOps example.
- **Topic lookup:** use the [book index](INDEX.md).

## Repository Conventions

- Section `README.md` files are the entry points for that section.
- Root-level Markdown files are navigation and planning documents; learning chapters live in their relevant sections.
- `solutions/` intentionally contains all implementation formats, including .NET apps, frontend samples, diagrams, and POCs.
- Content is evolving; broken links or outdated material should be treated as documentation issues to improve, not as canonical guidance.
