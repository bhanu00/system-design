# Solutions, POCs, and Application Samples

This section contains hands-on work in every relevant format: runnable applications, algorithm implementations, frontend samples, system-design diagrams, and proof-of-concept experiments. It is intentionally not limited to Markdown.

## Contents

| Area | Contents |
| --- | --- |
| `core-programming/` | C# implementations for arrays, collections, linked lists, queues, stacks, trees, strings, searching, and language concepts |
| `dotnet pocs/` | ASP.NET Core APIs and Docker-focused application samples |
| `front end/` | Angular application sample |
| `system design/` | System-design diagrams and supporting artifacts |

## How to use it

Read the relevant handbook chapter first, then use a sample here to validate the ideas by building, running, changing, and testing it. Each POC should eventually include a local README with setup, architecture, trade-offs, and verification steps.
